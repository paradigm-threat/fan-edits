# Welcome to the Flashback Repository

Personal fan edits of films I own — family-safe cuts, taste-driven mixes, and quiet repairs to movies that still matter.

This is not a pirate archive. **You must own a legal copy of each original** before you play anything here. That is the same rule the fanedit community has used for years.

**Copyrighted feature files are not in the git repos.** They live on **IPFS**. This site holds the **catalog** (notes, pointers, CIDs). Clients (Flashback app / some browsers) download masters **directly from the IPFS network** — Relay servers do not keep a hot movie cache. Details: [Ownership policy](/legal).

**Now showing** (carousel) is only what was **manually uploaded** for immediate play on the host. The full library below is the IPFS catalog; titles need a seeded peer to download.

## How to use it

1. **Confirm ownership** on the welcome screen (once per browser).
2. **Computer:** one-time VLC setup — see [Setup for playback](/setup). **Phone/tablet / Fire TV:** install the [Flashback App](/app).
3. **Pick a title** from the library below — each page explains what changed.
4. **Reaffirm for that film** the first time you open it (one checkbox; remembered forever on this device).
5. Play / download via IPFS (app or swarm), or use a Now showing title when listed.

Media rides **thin IPFS**: if a file is not on the network yet, it **needs to be seeded** — the hash is known; the bytes just are not available from any peer yet.

**Why this exists:** it is not only about better cuts. It is about whether we are **allowed** to improve the films we own and share those cuts with friends. [Read the full motivation →](/motivation)
