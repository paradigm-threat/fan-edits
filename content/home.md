# Welcome to the Flashback Repository

Personal fan edits of films I own — family-safe cuts, taste-driven mixes, and quiet repairs to movies that still matter.

This is not a pirate archive. **You must own a legal copy of each original** before you play anything here. That is the same rule the fanedit community has used for years.

**Copyrighted feature files are not in the git repos.** They live on **IPFS** (servers may cache blocks temporarily for streaming). Repos hold notes, edit projects, and text pointers — filenames in a `.kdenlive` file are not the film. Stream access on this site follows the ownership disclaimer. Details: [Ownership policy](/legal).

**Now showing** (carousel / marquee) is only what can be **played or downloaded on the server right now**. The full library stays listed below; titles that are not “now showing” may wait on IPFS peers.

## How to get a title

1. **Stream** — Open in VLC / Flashback app / Open stream link (same HTTPS `/ipfs/…` URL).
2. **Download** — Save the file to your device via this site’s IPFS gateway, then open it locally (not in-browser playback).
3. **Google Drive** — [Request downloads](/request) by email; an auto-reply sends the shared Drive library.

## How to use it

1. **Confirm ownership** on the welcome screen (once per browser).
2. **Computer:** one-time VLC setup — see [Setup for playback](/setup). **Phone/tablet / Fire TV:** install the [Flashback App](/app). **iPhone/iPad:** browser + VLC only (no sideload app).
3. **Pick a title** from the library below — each page explains what changed.
4. **Reaffirm for that film** the first time you open it (one checkbox; remembered forever on this device).
5. On a computer: **Open in VLC**, **Download** the file, or [Request Drive links](/request). On Android: Flashback app, external player, or download.

Media rides **thin IPFS**: the bytes are content-addressed on the network (not parked forever as public repo blobs). If a file is not seeded yet, it **needs to be seeded** — the hash is known; the bytes just are not available yet. Drive email still works when the swarm is quiet.

**Why this exists:** it is not only about better cuts. It is about whether we are **allowed** to improve the films we own and share those cuts with friends. [Read the full motivation →](/motivation)

**Want to contribute a cut?** Prefer an open-source NLE project (Kdenlive, Shotcut, OpenShot, Flowblade, Pitivi, Olive, …) so everything stays editable without proprietary tools. [Submissions →](/submit)
