# Request full-quality downloads

**Now showing** on the home page is only what this server can play or download **right now**. The rest of the catalog stays listed — you can still get every title.

## Three ways to get a movie

1. **Stream via IPFS** — On a title page, open the HTTPS stream in VLC / the Flashback app / Open stream link (when peers or the gateway have the CID).
2. **Download via IPFS** — Use **Download MKV/MP4** on the title page to save the file through this site’s gateway, then open it locally. This is not in-browser playback.
3. **Google Drive (this page)** — Email Ari with the exact subject below. Gmail sends one automatic reply with the shared Drive library and the story behind this project. Use this when you want offline copies without waiting on the swarm.

**You must own a legal copy of each original film** before you download an edit.

Use the form — it opens your local email app addressed to **ari@asu.edu** with the subject and a short body already filled (so the auto-reply filter matches). Send as-is. You should get the reply within a minute.
