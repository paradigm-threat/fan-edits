# Matrix Revolutions (2003) — Unlinked

A companion cut to Reloaded — Unlinked that trims many Link establishment sequences from *The Matrix Revolutions*.

## Motivation

Link was a poor replacement for Tank, who they killed off-screen. Revolutions still spends runtime on Link establishment beats that this edit removes so the finale can move without that hand-holding.

## Changes

- Removes many Link establishment sequences.
