# Fried Green Tomatoes (1991) — No Frank Bennett

Removes Frank Bennett as a face, voice, and name-driven plot thread so the Idgie / Ruth / Ninny / Evelyn emotional spine can lead.

## Why this cut

Frank’s antagonist thread (abuse, kidnapping, river dump, trial, barbecue revelation) dominates long stretches that pull focus from Whistle Stop and the friendship arc. Taking him out keeps that heart — accepting some ambiguity instead of endless courtroom and river beats.

## What changed

- Frank Bennett on-screen scenes removed
- Valdosta / river-club / abuse / kidnapping / investigation / trial thread removed
- Dialogue that names or explains Frank trimmed so he is not a plot dependency
