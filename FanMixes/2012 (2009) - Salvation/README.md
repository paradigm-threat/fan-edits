# 2012 (2009) — Salvation

A tighter cut of Roland Emmerich’s disaster epic that trims excess death spectacle and russophobic beats so the survival story can breathe.

## Motivation

The theatrical cut piles on unnecessary death scenes and cartoonish Russian-villain coloring that distract from the disaster-and-family core. This edit keeps the spectacle but drops the meanest, least useful of those beats.

## Changes

- Removes unnecessary death scenes and russophobic material.
