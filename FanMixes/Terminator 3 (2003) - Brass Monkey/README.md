# Terminator 3 (2003) — Brass Monkey Edition

In Brass Monkey Edition, I attempt to cut out all distracting dialog and sequences in Terminator 3 to be more like the first two movies.

## Motivation

Everything about T3 was lackluster compared to the prequels. I honestly think it all came down to bad editing as a result of in-fighting between the creators of T1/T2, otherwise I can't see why Mario Kassar failed so hard in T3. Clearly Terminator 3 is a victim of the 21st century.

## Changes

- Nick Stahl removed as much as possible, along with his narration.
- Stripper scene removed.
- Dialog about Kate worrying over her wedding removed.
- Many other distracting or contradictory scenes trimmed — e.g. a trailer-sequence “cash only” sign (phones down) that contradicts the clerk’s police call going through later.
- Background track “Dat Funky Man” replaced with Beastie Boys’ “Brass Monkey” (felt like the original song pick for that scene).
- Picture holes: **38** (~15.1 min). Cut list: [CHANGES.md](CHANGES.md) (many scene labels still TBD).
