# Thor Ragnarok (2017) — Kid friendly

A lighter *Thor: Ragnarok* timeline for family co-watch — same Sakaar / Asgard story, fewer hard edges.

## Motivation

Waititi’s Ragnarok is already colorful, but living-room playback still hits violence and adult digressions that force a remote-grab. This kid-friendly Kdenlive pass keeps the gladiator comedy and the Hela climax while easing those beats. (Cut list is the project timeline — not a full theatrical rewrite.)

## Changes

- Trims harder violence / adult digressions for family viewing.
- Keeps Sakaar, Valkyrie / Hulk, and the Asgard endgame.
