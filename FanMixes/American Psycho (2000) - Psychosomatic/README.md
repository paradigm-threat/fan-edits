# American Psycho (2000) — Psychosomatic

A leaner *American Psycho* that cuts some of Bateman’s longest self-mythology / body monologues so the satire and dread do not stall on vanity essays.

## Motivation

Theatrical Bateman already tells you he is empty; the film does not need every skin-care and blood-lust voiceover at full length. This edit removes about **13 minutes** across a handful of picture holes (including the long “beautiful skin” / inner-monster stretch) so the yuppie horror reads as **psychosomatic** — performance and panic — rather than a spa commercial with murders.

## Changes

- Trims extended Bateman body / blood-lust monologue blocks.
- Keeps the business-card / peer satire and core murder-mystery ambiguity.
- Shorter path through vanity digressions that pause the plot.
