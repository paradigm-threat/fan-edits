# The Day After Tomorrow (2004) — Yuppocolypse

A leaner *Day After Tomorrow* that spends less time establishing the yuppie protagonists before the climate disaster takes over.

## Motivation

The theatrical cut front-loads a lot of soft establishment for its well-off leads. This edit exists to cut that fat so the catastrophe story can dominate.
