# War of the Worlds (1953) — No Clip

A light trim of the 1953 *War of the Worlds* — short picture cuts only (~1 minute), not a rewrite of the classic.

## Motivation

A few brief clips interrupt the flow of the 1953 invasion (including a tight stretch of Psalm / church-adjacent beats mid-film). This edition is a **no-clip** polish: leave Haskin’s Martian war intact, drop only the smallest snags. Distinct from the 2005 *Family Therapy* Spielberg cut.

## Changes

- Four short picture holes (~0.9 min total).
- No major scene reorder; theatrical 1953 structure preserved.
